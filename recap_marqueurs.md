# 🛡️ Dungeon World – Fiche Exhaustive des Marqueurs d'Équipement, d'Armes & d'Armures

Cette fiche regroupe **l'intégralité des marqueurs** décrits sur la page officielle [pbta.fr](https://pbta.fr/wiki/dungeonworld:recrues_equipement#equipement).

## 🎒 1. Marqueurs Généraux d'Équipement

Ce sont les marqueurs généraux qui peuvent s’appliquer à n’importe quelle pièce d’équipement (armures, armes, fournitures et consommables).

| Marqueur | Description & Effet |
| :--- | :--- |
| **+Bonus / -Malus** | Modifie vos capacités dans une situation donnée (ex : *+1 à suivre sur étaler sa science*, *-1 continu sur tailler en pièces*). |
| **Appliquer** | À utiliser avec précaution directement sur une personne ou à lui faire consommer (dans sa nourriture/boisson). |
| **Dangereux** | Il est facile de s'attirer des ennuis avec. Si vous l'utilisez sans les précautions nécessaires, le MJ est libre de vous faire subir les conséquences de votre imprudence. |
| **2 mains** | Il faut obligatoirement utiliser ses deux mains pour s'en servir efficacement. |
| **Lent** | L'utilisation nécessite quelques minutes, voire davantage. |
| **Maladroit** | Peu maniable et difficile à utiliser. |
| **n Po** | Prix de l'objet en pièces d'or. Si le prix indique aussi `-Charisme`, un marchandage (pour la forme) permet de soustraire son score de Charisme au prix. |
| **n Poids** | Poids de l'objet pour l'encombrement. Tout objet sans poids (ou 0) n'entre pas dans le calcul. *(100 Po pèsent environ 1 poids)*. |
| **n Utilisations** | L'objet peut être utilisé **n** fois (cocher une case par utilisation). |
| **Porté** | Vous devez porter l'objet sur vous pour bénéficier de son effet. |
| **Ration** | Ça se mange, plus ou moins (sert de nourriture lors d'un campement ou voyage). |
| **Requiert** | Utilisable uniquement par certaines personnes (ex : race, classe, condition). Si la condition n'est pas remplie, l'objet ne fonctionne pas ou mal. |
| **Toucher** | L'effet se déclenche par contact direct avec la peau de la cible. |

## ⚔️ 2. Marqueurs d'Armes

Dans Dungeon World, les armes n'ont pas de dé de dégâts propre (les dégâts sont liés au playbook du personnage). Leurs marqueurs définissent leurs effets mécaniques, tactiques et narratifs.

### 📏 Portées d'Armes

#### Armes de Mêlée
- **Contact** : L'arme sert pour le combat au corps à corps strict, les empoignades, pas plus.
- **Proche** : Une arme pour atteindre ce qui se trouve à portée de bras (marqueur standard de la plupart des armes).
- **Allonge** : Arme permettant d'atteindre ce qui se trouve à quelques pas de soi (généralement les armes à deux mains et armes d'hast).

#### Armes de Jet / À Distance
- **Courte** : Arme efficace tant que vous voyez votre cible *dans le blanc des yeux*.
- **Longue** : Arme efficace tant que votre cible est *à portée de voix*.

---

### 💥 Effets et Propriétés des Armes

| Marqueur | Description & Effet |
| :--- | :--- |
| **n Munitions** | Quantité abstraite de projectiles pour l'arme de jet (ne représente pas un décompte exact de flèches ou carreaux, mais une réserve). |
| **Ignore l’armure** | Ne soustrayez pas l'armure de la cible lors du calcul des dégâts infligés. |
| **+n Dégâts** | Cette arme est particulièrement efficace. Ajoutez **n** aux dégâts infligés. |
| **n Perforant** | Cette arme traverse les armures. Soustrayez **n** du montant d'armure de l'ennemi. |
| **Puissant** | Peut repousser quelqu'un, voire lui faire perdre l'équilibre. |
| **Dévastateur** | L'arme inflige des dégâts particulièrement spectaculaires. Êtres vivants ou objets sont déchiquetés. |
| **Précis** | Cette arme favorise la finesse et utilise le modificateur de **DEX** au lieu de **FOR** pour *Tailler en pièces*. |
| **Recharge** | Après une attaque, il faut du temps pour réarmer avant de s'en resservir. |
| **Assomme** | Provoque des étourdissements au lieu de dégâts normaux. |
| **Lancé** | Arme projetée pour blesser (usage unique). Un 7-9 sur une *Salve* avec cette arme ne permet pas de choisir l'option d'enlever une munition. |

## 🛡️ 3. Marqueurs d'Armures

| Marqueur | Description & Effet |
| :--- | :--- |
| **n Armure** | L'armure vous protège des attaques et absorbe les dégâts. Quand vous prenez des dégâts, soustrayez le chiffre d'armure du total. *(Si vous portez plusieurs objets avec n Armure, seul le plus haut chiffre est pris en compte)*. |
| **+n Armure** | L'objet vous protège et se cumule avec d'autres armures. **n** s'additionne à votre total d'armure. |
| **Encombrant** | Il est difficile de se déplacer avec ça sur le dos. Applique **-1 cumulatif** aux actions lorsque l'on s'en sert. |
